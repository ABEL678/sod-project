## 8. Замечания

Итог: визуальное кодирование статусом фона — суть У6-а — не работает; статус остаётся читаем только через иконку+слово (правило №2 спасает информативность, но не дизайн). **Фикс (7 строк, `redesign.css:1031–1037`):** поднять специфичность родителем, например `.task-matrix .task-matrix__cell--done { … }` (0,2,0) — для всех 7 модификаторов (и диагональ/пустая ячейка не трогать).
