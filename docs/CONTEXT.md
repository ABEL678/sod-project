# CONTEXT.md — Контекст для новой сессии

**Дата:** 28.10.2026

## Что мы строим?
СОД (Среда Общих Данных) для проектной компании на 25 человек.
Стек: Python 3.14, Django 5+, SQLite. Архитектура: Модульный монолит («гексагон лайт»).

## Что уже работает?
Мы реализовали базовый MVP:
1. Модели: Проекты, Разделы, Документы, Версии, Замечания.
2. Бизнес-логика в `storage/domain/services.py` (версионирование, права).
3. UI: Drag-and-Drop загрузка файлов, таблица документов, история версий.
4. Экспорт ведомости в Excel.
5. Модуль замечаний (`issues`).
6. Авторизация (вход/выход).
7. Симуляция импорта из почты.

## Что делаем прямо сейчас?
MVP готов. Мы на этапе тестирования и сбора обратной связи от реального использования. 

## Правила для ИИ
1. Всегда читай `ARCHITECTURE.md` и `MASTER_SPEC.md`.
2. Бизнес-логика только в `services.py`.
3. После написания кода — отправляй его на проверку Аудитору (DeepSeek).
