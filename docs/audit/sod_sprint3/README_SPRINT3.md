## Что сделано (15 пунктов + бонус)

### P1 — защищают сделанное
1. **Pointer Events для T65** — разделитель «наложения» тянут пальцем и
   стилусом на планшете стройплощадки (`setPointerCapture`, фолбэк на
   window-события; `touch-action: none` уже был в viewer.css).
2. **Локальные шрифты, ноль CDN** — Golos Text (вариативный, 400–600),
   JetBrains Mono и bootstrap-icons лежат в `static/fonts/`; CDN-ссылки
   удалены из base.html, document_detail.html **и из @import в app.css**
   (скрытая зависимость, найденная при проверке). Шрифты добавлены в
   пре-кэш сервис-воркера. Живая проверка: 0 запросов к CDN.
3. **Пять регрессионных тестов** (`issues/tests/test_sprint3.py`) —
   formula injection в Excel, права реестра, права палитры, scope
   проверяющего в workflow, эквивалентность сервиса прав. **289/289 OK.**

### P2 — устойчивость к росту
4. **`get_readable_documents` без N+1** — ролевые SQL-фильтры вместо
   по-документного `check_read_permission` (реестр, палитра, Excel).
   Правила те же — эквивалентность покрыта тестом.
5. **sw-bypass-list.js из urls.py** — четвёртый артефакт генератора
   `build_design_tokens.py` (CI ловит дрейф). Список больше не зашит в
   sw.js руками; заодно закрыты дыры: `/my-issues/` и `/notifications/`
   раньше вообще не были в bypass и тихо кэшировались как статика.
6. **Версия кэша SW из хэша статики** — `/sw.js` отдаёт
   `sod-shell-<md5-пре-кэша>`; ручной бамп CACHE_NAME не нужен.
7. **offline.html на токенах** — вместо инлайн-hex: `var(--c-bg-app)`,
   `var(--c-accent)` и т.д.; tokens.css в пре-кэше.

### P3 — мелочи
8. Заглушка `toggleOverlay` (alert) удалена; режим T65 переименован в
   «Наложение», тултип объясняет перетаскивание мышью/пальцем/стрелками.
9. Единый формат дат `d.m.Y, H:i` с табличными цифрами (карточка,
   «Мои замечания», уведомления).
10. Водяной знак: opacity 0,25 → 0,12.
11. Тултипы ‹ › упоминают клавиши P и N; сами клавиши добавлены
    (`event.code` — работают в любой раскладке, в полях ввода — нет).
12. «Последние документы»: чипы с типом, версией и временем открытия
    (время в сессии, старые сессии совместимы).
13. Плейсхолдер шифра: `26-11-02-Северный` + подсказка формата.
14. «Импорт/Экспорт/Настройки» свернуты в меню «⋯».
15. Пустое состояние реестра: CTA «создаётся кликом по листу» + ссылка
    на документы проекта.

**Бонус (найдено тестом №1):** Excel-экспорт реестра падал с
`ValueError: Colors must be aRGB hex values` на каждом запросе — токены
отдавали цвета с «#», openpyxl их не принимает. Генератор теперь отдаёт
Python-константы без решётки. Экспорт восстановлен.

## Установка

```bash
git apply --check sod_sprint3.patch   # на ревизии 5657388 — чисто
git apply sod_sprint3.patch
cp -r файлы/static/fonts static/      # бинарные шрифты (патч их не переносит)
python manage.py check                # без замечаний
python manage.py test                 # 289/289 OK
python scripts/build_design_tokens.py --check   # синхрон с urls.py
```

Без git: скопируйте содержимое `файлы/` поверх корня проекта.

## После установки — проверка за 5 минут

1. `/projects/1/` — чип «Последние документы» с типом, версией и временем.
2. Кнопка «⋯» в панели документов — три пункта внутри.
3. Вьювер не-current версии — кнопка «Наложение»; откройте на планшете
   и потяните шторку пальцем.
4. Клавиши N/P листают страницы (в тултипах ‹ › подписано).
5. Реестр нового проекта без замечаний — CTA вместо тупика.
6. Excel-экспорт реестра — скачивается, шапка залита фирменным цветом.
7. DevTools → Application → Service Workers: кэш `sod-shell-<хэш>`;
   вкладка Network при офлайне — шрифты из кэша, 0 запросов к CDN.
