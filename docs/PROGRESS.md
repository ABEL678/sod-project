## Аудит 4.0 (Спринты 5–6 и Бэклог)

### Спринт 5 — Безопасность и логика
- Fail-closed настройки: отсутствие обязательных env-переменных останавливает приложение, а не открывает доступ.
- Валидация загружаемых файлов (тип, размер, содержимое) до создания версии.
- Матрица прав на ответ замечания: отвечать может только пользователь с соответствующими правами.
- Share-токены: публичная ссылка не отдаёт замечания и не раскрывает внутренние данные.
- `transaction.on_commit` при очистке корзины — побочные эффекты только после успешного коммита.
- Синхронизация триплета копии (документ → папка → раздел/проект) при копировании.
- Устранён N+1 при подсчёте документов: аннотация `Count` вместо запросов в цикле.

### Спринт 6 — UX
- Токены: кислотный синий заменён на утверждённый акцент палитры.
- Контраст: приглушённые (`muted`) тексты и рамки приведены к читаемым значениям.
- Кнопка «Загрузить» получила `aria-live` для озвучивания состояния загрузки.
- Кебаб-меню папок вместо перегруженного набора действий.
- Единые шрифты и исправленная вёрстка модалки перемещения.

### Первый эшелон бэклога
- N+1 в списках документов устранён.
- Share-токены: срок действия 1 год, отзыв ссылки, создание через POST.
- FSM для документов: переходы статусов контролируются явной машиной состояний.
- Идентификация зон по полю `Folder.is_system_zone`, а не по имени папки.
- Модельный guard в `Document.save()`, запрещающий недопустимые изменения статуса в обход сервисов.

### Второй и третий эшелон
- `restore_project` с отдельным флагом `deleted_with_project` для корректного восстановления.
- Мобильная раскладка (<820px): offcanvas-сайдбар и адаптивная таблица.
- Миграция CSS на дизайн-токены: 178 замен, линтер `check_raw_hex.py` против сырых hex-значений.
