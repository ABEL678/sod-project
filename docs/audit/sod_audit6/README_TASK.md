## Git: как вернуть задеплоенное (GitHub уехал вперёд — 5A/5B/5C)

Сначала выяснить, что реально на сервере: `git log --oneline -1` (или сверить
`git hash-object static/js/pdf_viewer.js ...` против `git rev-parse 59faf20:static/js/pdf_viewer.js`).

- **А (рекомендуется):** `git checkout -b hotfix/audit6 59faf20` → патч → коммит →
  `git push -u origin hotfix/audit6`. Деплой с этой ветки; main чистится отдельно.
- **Б (main к содержимому 4D, история целa):**
  `git branch backup/5x fe2af42` → `git checkout main` →
  `git revert --no-commit fe2af42 503089a c32f5f3` → `git commit` → push.
- **В (радикально, только если работаете один):** `git branch backup/5x fe2af42` →
  `git reset --hard 59faf20` → `git push --force-with-lease origin main`.

5A/5B/5C не удалять молча: сохранить в `backup/5x` и разбирать отдельно (API Gateway,
TTL, N+1 — самостоятельные решения владельца; 5B трогает запрещённый services.py).

Деплой — всегда ОДНИМ коммитом; смешанные файлы = «тёмное на тёмном» и рассинхроны.
