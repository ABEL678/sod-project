## Спринт 5 · надёжность и безопасность (коммит f730ecc)

1. Зоны ISO 19650: запрет выносить документы из SHARED/PUBLISHED/ARCHIVE переносом
   в другой раздел (обходной путь вокруг move_document).
2. Матрица прав на ответ замечания: исполнитель/разработчики проекта/ГИП/админ;
   наблюдатель, заказчик и проверяющий — только чтение.
3. Валидация загрузок: белый список 25 форматов СЭД, лимит 100 МБ, отказ пустых файлов.
4. Настройки fail-closed: явный DJANGO_DEBUG=False без DJANGO_SECRET_KEY — ошибка старта;
   локальный запуск без .env поднимается с предупреждением.
5. Парольная политика при создании пользователя (validate_password).
6. Публичная share-ссылка больше не отдаёт замечания (тексты, авторов, ответы).
7. Очистка корзины: файлы удаляются после commit (on_commit), маркапы замечаний тоже.
8. Копия документа: статус-триплет синхронизируется с целевой папкой.
9. Сохранённые виды: фильтры suitability_code/internal_status применяются к списку.
10. Безопасные имена файлов в скачивании и PDF-экспорте (get_valid_filename).
11. Проверяющий с ролью viewer больше не проходит workflow-проверку.
12. 12 устаревших тестов актуализированы под контракт T67/T68; +18 новых тестов.

## Спринт 6 · UX-полировка (коммит 43b78ee)

1. Видимая кнопка «Загрузить» в тулбаре реестра + живой статус загрузки (aria-live).
2. Спиннер HTMX-обновлений панели; тосты на htmx:responseError/sendError.
3. Кебаб-меню папки (видимая кнопка, hover/фокус) + закрытие контекстного меню по Escape.
4. Страница входа: tokens.css и шрифты — кнопка «Войти» снова фирменного цвета.
5. Шрифты Golos Text/JetBrains Mono на всех страницах; skip-link; id=main-content;
   aria-label для поисков.
6. Контраст через токены: muted #71716A (4.54:1), рамки хедера #8A93A6 (3.13:1).
7. Вытравлены кислотные синие: 22 значения в app.css, 3 в viewer.css → var(--c-accent).
8. Общие блоки (dndToast, docRowMenu, documentMoveModal) вынесены из цикла разделов —
   дублирующиеся ID устранены.
9. Вьювер: bootstrap-icons вместо юникод-глифов, тосты вместо alert().
10. Плюрализация «1 файл / 2 файла / 5 файлов», улучшенный текст подтверждения удаления.
11. theme-color синхронизирован (#3A4558), мёртвые правила удалены.
12. +5 тестов разметки (Sprint6MarkupTests).

## Установка

```bash
# база: чистый origin/main af4a72d (или ваше текущее состояние на его основе)
git apply --check sod_sprint5.patch && git apply sod_sprint5.patch
git apply --check sod_sprint6.patch && git apply sod_sprint6.patch
python manage.py test        # ожидается: Ran 326 tests — OK
python manage.py runserver
```

Если `git apply` конфликтует (например, у вас уже применён Спринт 3 или свои правки) —
скопируйте файлы из `файлы/` поверх репозитория, сохранив пути.

- Миграций БД **не требуется**.
- Откат: `git checkout af4a72d -- .` (или git reset --hard af4a72d на чистой ветке).
- Патчи независимы от Спринта 3 (зачистки 5657388): конфликтов по файлам нет,
  её можно применить до или после.
