# СОД для проектной компании

Внутренняя система общих данных (СОД) для небольшой проектной компании (25 человек).

## Документация
- [Архитектура](docs/ARCHITECTURE.md) — как устроена система, модели данных, правила для разработки, интеграция с экосистемой.
- [Мастер-спека](docs/MASTER_SPEC.md) — что делаем, этапы и контрольные точки.
- [Статус проекта](docs/PROGRESS.md) — что сделано и что дальше.
- [Контекст для ИИ](docs/CONTEXT.md) — краткое резюме для новой сессии.

## Экосистема
СОД (Stream-CAD) является центральным API-хабом (Gateway) для:
1. **ГИП-Ассистент** (FastAPI/React) — управление задачами (Goal/Decision/Task/RFI).
2. **ВОР-билдер** (Python/NiceGUI) — генерация ведомостей объёмов работ (ВОР).
3. **Витро-трекер** (Python/Streamlit) — синхронизация замечаний из Витрокад.

Интеграция с этими системами осуществляется через REST API СОД (см. раздел 6 в Архитектуре).

## Стек
- Python 3.14
- Django 5+
- SQLite (на старте), PostgreSQL (на сервере через переменные окружения)
- Bootstrap 5 + ванильный JS (без React/Vue)
- ИИ-агент Kilo (PyCharm) для разработки
- Тестирование: `pytest-django` (110+ тестов)

## Ключевые возможности
- **Ядро:** Проекты, разделы, документы с версионированием.
- **Права:** Роли (admin, gip, engineer, viewer, contractor), мультитенантность.
- **Поиск:** Поиск по шифру, названию, комментарию версии с фильтрами.
- **GUI:** Сохраняемые виды таблиц, счётчики разделов, вкладка «Участники».
- **Замечания:** Создание замечаний к документам и версиям, смена статусов.
- **Экспорт:** Ведомости в Excel с гиперссылками.
