```python
def _create_default_zones(project, created_by):
    """Создаёт 4 корневые папки-зоны для проекта."""
    zone_configs = [
        ('WIP', '01. В работе'),
        ('SHARED', '02. На согласовании'),
        ('PUBLISHED', '03. Опубликовано'),
        ('ARCHIVE', '04. Архив'),
    ]
    for idx, (zone, name) in enumerate(zone_configs, 1):
        Folder.objects.create(
            project=project,
            section=None,
            parent=None,
            name=name,
            order=idx,
            zone=zone,
            created_by=created_by,
        )
```

**Миграция для существующих проектов:**
- При первом открытии страницы проекта проверить, есть ли зоны. Если нет — создать через сигнал `post_migrate` или management-команду.
- Использовать Django signal `post_migrate` в `storage/apps.py` для автоматического создания зон для старых проектов.

### ШАГ 4: Права на основе зон
**Файлы:**
- `storage/domain/services.py` — добавить `check_zone_permission()`

**Логика:**
```python
def check_zone_permission(user, folder, action='write'):
    """Проверка прав доступа к зоне."""
    if folder is None:
        # Нет папки — старые правила (через section)
        return True  # будет проверено отдельно
    
    zone = folder.zone
    if zone == 'ARCHIVE':
        return action != 'write'  # только чтение
    
    if zone == 'PUBLISHED':
        return user.is_superuser or (
            getattr(user, 'userprofile', None) and
            user.userprofile.role == 'admin'
        )
    
    if zone == 'SHARED':
        # Только ГИП и админ
        profile = getattr(user, 'userprofile', None)
        if profile is None:
            return False
        if profile.role == 'admin':
            return True
        if profile.role == 'gip':
            return project.memberships.filter(
                user=user, role_in_project='gip'
            ).exists() or project.gip_id == user.id
        return False
    
    if zone == 'WIP':
        # Инженеры, ГИП, админ
        return check_write_permission(user, folder.section or document.section)
```

**Интеграция:**
- В `upload_document()` проверять зону папки перед загрузкой
- В `move_document()` проверять зону целевой папки
