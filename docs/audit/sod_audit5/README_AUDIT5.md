## Спринт 7 · надёжность и контракт перемещений (b0b305b)

1. DnD-контракт: сброс документа в корень СВОЕГО раздела — без подтверждения;
   кросс-разделный перенос — confirm + `allow_section_change=1`; папки в чужую
   марку — подсказка «используйте кнопку "Сменить раздел"» без запроса.
2. «Последние документы» перенесены со страницы проекта (шум) в пустое
   состояние поиска (отправная точка); мёртвый контекст удалён.
3. create_demo_project не запускается в продакшене без `--force` (демо-аккаунты
   с известным паролем demo12345 и ролью admin = обход аутентификации).
4. Скриншоты обратной связи проверяются PIL: подделанный content_type больше
   не пропускает битые байты.
5. LOGGING настроен (django.request WARNING, storage/issues INFO, DJANGO_LOG_LEVEL).
6. 4 падающих теста базовой линии актуализированы/починены, +17 новых тестов.

## Спринт 8 · светлый хедер, фильтры, вьювер (59f2820, 50df590, 7b97e65)

1. Светлый хедер #FFFFFF через токены: on-dark #1F2430 / #5D6575 (контраст 4.5:1+),
   рамки #E1E5EC / #7C8698, лого-марка — акцент #3D5A98, theme-color #FFFFFF
   (base.html, document_detail.html, manifest).
2. Видимый фильтр-бар: селекты Раздел/Тип/Статус/Пригодность/Внутр. статус + поиск,
   авто-применение; строка «Отфильтровано:» с чипами «Параметр: значение ×»
   и счётчиком; «Сбросить всё»; колоночные воронки и их мёртвый CSS удалены.
3. Вьювер: рабочая полоса листов (ленивые миниатюры IntersectionObserver,
   активная страница, клик-переход).
4. Наложение чертежей: прозрачность 5–100%, режимы Обычный/Разница/Умножение,
   совмещение перетаскиванием и стрелками (Shift — шаг 10px). Меню «Сравнить»
   с выбором версии-цели — доступно из любой версии (раньше кнопки были
   задизейблены на текущей).
5. N+1 реестра устранён: 345 → 32 SQL-запроса; стабильно при 300 документах.
   Скрипты замеров: `scripts/perf_probe.py`, `perf_profile.py`, `perf_trace.py`.
6. Тестовая база: 383 теста — все зелёные.

## Установка

```bash
# база: чистый origin/main 92f237c (или ваше состояние на его основе)
git apply --check sod_sprint7.patch && git apply sod_sprint7.patch
git apply --check sod_sprint8.patch && git apply sod_sprint8.patch
python manage.py migrate          # миграций в спринтах нет — команда ничего не изменит
python manage.py test             # ожидается: Ran 383 tests — OK
python manage.py runserver
```

Если `git apply` конфликтует — скопируйте файлы из `files/` поверх репозитория,
сохранив пути. Откат: `git checkout 92f237c -- .`.

- Миграций БД **не требуется**.
- Токены синхронны: `python scripts/build_design_tokens.py --check` — OK.
- Проверка производительности: `python manage.py shell < scripts/perf_probe.py`.
