# СОД Stream-CAD — Спринт 4 · дизайн-полировка

Комплект закрывает запрос «убрать кислотный синий и придумать красивый хедер»
и заодно доставляет зачистку из «Аудита 3.0», пересаженную на ваш текущий код.

**База: `d2ca02a`** — это ваш текущий `main` (T66 зонные права + T67 папки/ГОСТ).
Старые спринты в комплект не входят — они уже у вас в продакшене.

## Состав архива

```
sod_sprint4/
├── README_SPRINT4.md              ← этот файл
├── sod_design4.patch              ← патч 1: дизайн (13 файлов, +246/−154)
├── sod_cleanup_on_design4.patch   ← патч 2: зачистка поверх дизайна (35 файлов)
├── файлы/                         ← полные версии всех 39 изменённых файлов
│                                    (включая бинарные шрифты — патч их не переносит)
└── скриншоты/                     ← 5 живых состояний итогового вида
    ├── s4_project_list.png        графитовый хедер, список проектов
    ├── s4_project_detail.png      таблица документов, поиск-пилюля, чипы зон
    ├── s4_viewer.png              вьювер: «Наложение», пины, панель замечаний
    ├── s4_registry.png            реестр: единая гамма статусов вместо пестроты
    └── s4_my_issues.png           «Мои замечания»: дедлайны и чипы
```

## Установка (два патча строго по порядку)

```bash
git checkout main && git pull                 # убедитесь, что вы на d2ca02a
git apply --check sod_design4.patch           # dry-run: должно пройти молча
git apply sod_design4.patch
git apply --check sod_cleanup_on_design4.patch
git apply sod_cleanup_on_design4.patch
cp -r файлы/. .                               # полные версии + бинарные шрифты
python manage.py test                         # должно быть 303/303 OK
```

Миграций в комплекте нет — накатывать `migrate` не нужно.
Если деплой с `collectstatic` — не забудьте пересобрать статику.

> Если зачистка не нужна, примените только `sod_design4.patch` и скопируйте
> файлы — дизайн самодостаточен. Но зазор между патчами не оставляйте надолго:
> после зачистки пропадёт последняя зависимость от CDN (иконки и шрифты).

## Что изменилось в дизайне (патч 1)

### Кислотный синий больше не существует
- Акцент системы: `#2F5BEA` → **`#3D5A98`** (графит-синий, «чертёжная тушь»):
  кнопки, ссылки, табы, зоны, фокус-кольца, командная палитра, активные
  состояния — всё из токенов, всё согласованно (контраст на белом 6,7:1).
- **Bootstrap перекрашен**: раньше `.btn-primary`, ссылки и фокусы были
  бутстраповским `#0d6efd` в обход токенов — именно поэтому «кислота»
  выживала. Теперь `btn-primary`, `btn-outline-primary`, ссылки, чекбоксы,
  выпадашки и пагинация берут `var(--c-accent)`.
- Тёмная тема: акцент `#6B8BFF` → спокойный `#5474AC` (контраст с белым 4,7:1).

### Хедер: графит вместо mint
- `--c-bg-header`: `#DCFCE7` → **`#1F2937`**, граница `#374151`.
- Лого-марка «СОД» — белая, крошки — светло-серые, водяной знак Stream-CAD —
  призрак (0,12).
- Кнопки хедера — ghost-стиль: прозрачные, светлая рамка `#4B5563`,
  при ховере — мягкая заливка и акцентная рамка.
- Поиск — тёмная пилюля с холодным фокус-кольцом; аватар — с кольцом.
- `theme-color` (мета и PWA-манифест) — графит: браузер на телефоне
  окрашивается в тон хедера.

### Статусы и чипы: единая приглушённая гамма
Сырые цвета Bootstrap (`#0d6efd`, `#0dcaf0`, `#ffc107`, `#dc3545`) заменены
на выровненную палитру — один тон, одна насыщенность. Все пары проверены на
WCAG AA (≥ 4,5:1):

| Статус | было | стало (solid) | маркер/белый | бейдж on/subtle |
|---|---|---|---|---|
| Новое | `#0d6efd` | `#4674A4` | 4,9 | 6,2 |
| В работе | `#0dcaf0` | `#2E7D8C` | 4,7 | 6,4 |
| К обсуждению | `#ffc107` | `#9A650F` | 5,0 | 6,0 |
| Не принято | `#dc3545` | `#B44E48` | 5,1 | 6,4 |
| Выполнено | `#198754` | `#3F7D56` | 4,9 | 6,6 |
| Закрыто | `#6c757d` | `#5D6770` | 5,8 | 6,8 |
| Аннулировано | `#212529` | `#3F3F3C` | 10,6 | 12,8 |

Заодно переведены на токены: бейджи документов и ролей, тосты загрузки,
пины и маркапы вьювера, подсветка активной строки таблицы, жёлтые
«просрочки» и алерт-полосы. Зашитых кислотных hex в CSS/шаблонах не осталось
(проверено grep'ом; единственные hex — в комментариях tailwind-конфига).

## Что изменилось в зачистке (патч 2, пересаженная)

Это тот же «Спринт 3 · зачистка», но перебазированный с `5657388` на
дизайн-состояние: конфликтов с T66/T67 больше нет. Состав не изменился:

1. **Pointer Events для T65** — разделитель «Наложения» тянется пальцем
   и стилусом (`setPointerCapture`, фолбэк на window-события).
2. **Локальные шрифты, ноль CDN** — Golos Text, JetBrains Mono и
   bootstrap-icons лежат в `static/fonts/`; CDN-ссылки удалены из шаблонов
   и из `@import` в app.css; шрифты в пре-кэше сервис-воркера.
3. **Пять регрессионных тестов** на security-фиксы команды (formula
   injection, права реестра/палитры, scope проверяющего, эквивалентность
   сервиса прав).
4. **`get_readable_documents` без N+1** — ролевые SQL-фильтры вместо
   по-документного перебора (реестр, палитра, Excel).
5. **sw-bypass-list.js генерируется из urls.py** (четвёртый артефакт
   `build_design_tokens.py`, CI ловит дрейф) + закрыты дыры `/my-issues/`
   и `/notifications/` в bypass-списке.
6. **Версия кэша SW из хэша статики** — ручной бамп CACHE_NAME не нужен.
7. **offline.html на токенах**, единый формат дат `d.m.Y, H:i` с табличными
   цифрами, тултипы и клавиши P/N, чипы в «Последних документах», меню «⋯»,
   водяной знак 0,12.

Единственная содержательная правка относительно старого зачисточного патча:
положительный контроль в тесте workflow учитывает правило T67 «подать на
согласование можно только после статуса "Готов к передаче"» — раньше тест
создавал документ и жаловался, теперь честно готовит его к подаче.
