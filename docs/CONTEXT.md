# CONTEXT.md — Контекст для новой сессии

**Дата:** 27.10.2026

## Что мы строим?
СОД (Среда Общих Данных) для проектной компании на 25 человек. 
Стек: Python 3.14, Django, SQLite. Архитектура: Модульный монолит с «гексагон лайт».

## Что уже работает?
- База данных развернута, миграции применены.
- Написаны все 6 моделей (Проекты, Разделы, Документы, Версии, Пользователи).
- Настроен репозиторий на GitHub (ветка `master`).
- Настроены роли ИИ-агентов в Kilo (Code = Nemotron, Ask/Auditor = DeepSeek).

## Что делаем прямо сейчас?
Пишем файл `storage/domain/services.py`. 
В нем нужны 3 функции:
1. `check_write_permission`
2. `upload_document` (главная логика версионирования)
3. `generate_vedomost`

## Правила для ИИ
1. Всегда читай `ARCHITECTURE.md` и `MASTER_SPEC.md`.
2. Бизнес-логика только в `services.py`.
3. После написания кода — отправляй его на проверку Аудитору (DeepSeek).
