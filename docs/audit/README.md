# Артефакты UI/UX аудита

Здесь собраны отчеты аудита и связанные с ними артефакты.

## История аудитов
### Аудит 1.0 (30–31.10.2026)
- **Файл:** `Аудит_Среды_общих_данных_CDE.pdf` (и его ранняя версия `СОД_Stream-CAD_аудит_интерфейса.pdf`)
- **Суть:** первичный аудит интерфейса. Выявлены 3 системных риска (файловая метафора, сломанная семантика цветов, отсутствие продуктового характера). Предложен план из 3 волн.
- **Статус:** Волна 1 закрыта на ~65%. На этот отчет ссылается Аудит 2.0.

### Аудит 2.0 (01.11.2026, ревизия d31a453)
- **Файл:** `СОД_Stream-CAD_Аудит_2.0.pdf`
- **Патч:** `sod_sprint1.patch` (Спринт 1 «Быстрые победы 2.0» — 9 файлов, +256/-22, без миграций).
- **Суть:** повторная проверка кода. Подтверждено закрытие Волны 1 (~65%), Волна 2 (~40%), Волна 3 (~5%). Предложен конкретный патч для Спринта 1.
- **Статус:** Спринт 1 применён. Спринт 2 (консолидация) и Волна 3 (workflow ISO 19650) — в планах.

### Аудит 2.0 — Волна 3 (01.11.2026)
- **Файл:** `README_WAVE3.md`, `sod_wave3.patch`
- **Суть:** Реализация продуктового характера: зоны ISO 19650, workflow-кнопки, уведомления, «Мои замечания», кластеризация маркеров, палитра Ctrl+K, PWA. 
- **Статус:** Применено (коммит `6c997f2`). A21, T65 и Спринт 2 сохранены. Безопасность (SW cache, IDOR) закрыта.

## Важное замечание (отклоненные артефакты)
Визуальные прототипы из аудита (`cde-viewer-prototype.html`, `preview.html` и др.) **НЕ ПРИНЯТЫ** заказчиком.
**Причина:** в них маркапы изображены как кружки без рамок. Заказчик требует, чтобы маркапы были с рамками (bounding boxes), так как инженерам нужно видеть границы области замечания.
Поэтому эти файлы не включены в проект. Их не нужно использовать как референс.
