# Артефакты UI/UX аудита

Файлы аудита лежат в `docs/audit/` (PDF) и `static/design-tokens/` (токены).

## Важное замечание (отклоненные артефакты):
Визуальные прототипы из аудита (`cde-viewer-prototype.html`, `preview.html` и др.) **НЕ ПРИНЯТЫ** заказчиком.
**Причина:** в них маркапы изображены как кружки без рамок. Заказчик требует, чтобы маркапы были с рамками (bounding boxes), так как инженерам нужно видеть границы области замечания.
Поэтому эти файлы не включены в проект. Их не нужно использовать как референс.
