# CONTEXT.md — Контекст для новой сессии

**Дата:** 29.10.2026

## Что мы строим?
СОД (Среда Общих Данных) для проектной компании на 25 человек.
Стек: Python 3.14, Django 5+, SQLite/PostgreSQL. Архитектура: Модульный монолит («гексагон лайт»).

## Что уже работает?
Мы реализовали базовый MVP:
1. Модели: Компании, Проекты, Разделы, Документы, Версии, Замечания, Виды таблицы (DocumentView).
2. Бизнес-логика в `storage/domain/services.py` (версионирование, права, виды).
3. UI: Drag-and-Drop загрузка файлов, таблица документов, история версий, вкладка «Участники».
4. Экспорт ведомости в Excel.
5. Модуль замечаний (`issues`).
6. Авторизация (вход/выход).
7. Поиск по ревизиям.
8. Симуляция импорта из почты.

## Что делаем прямо сейчас?
MVP готов (Этапы 1-7). Мы на этапе подготовки к **Этапу 8 (PDF-вьюер и пины)** и **Этапу 7 (Layout Overhaul)**.

## Экосистема
СОД будет центральным API-хабом для:
1. **ГИП-Ассистент** (FastAPI/React) — управление задачами.
2. **ВОР-билдер** (Python/NiceGUI) — генерация ВОР.
3. **Витро-трекер** (Python/Streamlit) — синхронизация замечаний.

## Правила для ИИ
1. Всегда читай `ARCHITECTURE.md` и `MASTER_SPEC.md`.
2. Бизнес-логика только в `services.py`.
3. Не создавать API-эндпоинты напрямую во views — только через сервисы и порты.
4. После написания кода — отправляй его на проверку Аудитору (DeepSeek).
